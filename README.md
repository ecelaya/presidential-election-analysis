# 🗳️ U.S. Presidential Election & Demographic Analysis (1976–2020)

This project explores how state-level demographic factors relate to presidential election outcomes in the U.S. from 1976 to 2020.

## 📌 Description
I cleaned and merged presidential election data (MIT Election Lab) with census demographic data to explore how variables like income, education, and race correlate with election results across states and years. The analysis includes summary tables, visualizations, and interpretation of trends.

## 🔧 Tools & Packages Used
- R, R Markdown
- tidyverse, skimr, lubridate, janitor, flextable, ggplot2, flextable, stringr, patchwork, ggthemes, ggpubr, worldcloud2

## 📁 Project Files
- `Final_Report_Eloy.Rmd` – Full analysis written in R Markdown
- `Final_Report_Eloy.Rmd` – knitted report to PDF
- `elections_data.csv` – Raw election results dataset (1976–2020) from MIT Election Lab  
- `census_data.csv` – State-level demographic and economic data (2008–2021) from the U.S. Census

## 🎯 Project Goals
- Clean and merge state-level election and demographic data
- Visualize voting trends and socioeconomic factors by party and year
- Identify demographic patterns linked to Republican vs. Democrat wins

## 📊 Key Insights
- Democrat states had higher median income and lower poverty rates (2008–2020)
- Median rent and income have both risen in parallel
- Party trends over time show persistent popular vote wins for Democrats since 2008
